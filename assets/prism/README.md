# Vendored Prism.js (1.29.0)

Client-side highlighter for the Jog public wiki.

| File | Role |
|------|------|
| `prism.min.js` | Prism core |
| `prism-jog.js` | Custom Jog grammar (keywords, types, comments, strings, numbers, operators) |
| `components/*.min.js` | Official langs: bash, c (+clike), cmake, json, zig |

Downloaded from cdnjs (`ajax/libs/prism/1.29.0`). License: MIT (PrismJS).

Token colors live in `../wiki.css` (not a stock Prism theme) so they match the wiki’s dark green code blocks.
